# 푸딩 탈출 AI 아레나

같은 시작 상태에서 두 AI의 첫 조작을 보고 승자를 고르는 3라운드 웹게임입니다. 조작을 선택하면 같은 시간축에서 두 리플레이를 재생합니다. 공개 기록을 [시나리오 원본](../../results/2026-11-22-public/README.md)에서 가져옵니다.

## 실행

저장소 루트에서 Node.js 22.18 이상으로 실행합니다.

```sh
npm run arena
```

콘솔에 표시된 로컬 주소를 엽니다. `npm run arena:build`는 서버를 시작하지 않고 `bench-out/arena/`에 정적 웹 파일을 생성합니다. 브라우저에서 공개 행동 기록을 재생하므로 API 키 없이 실행할 수 있습니다.

빌드는 공개 아카이브의 환경 버전을 확인하고 기존 시나리오 검증 명령을 실행합니다. 그 버전의 `src/sim/`을 브라우저용 JavaScript로 변환하고, 아레나에서 사용하는 아홉 사례를 묶습니다. 첫 행동 뒤에는 원본 `fullCharge` 정책으로 최대 3초간 진행합니다. `npm test`는 모든 모델 리플레이의 결과를 공개 기록과 대조합니다.

## 소스

- `index.html`, `arena.css`와 `arena.js`에 3라운드 화면, 예측 선택, 리플레이 및 직접 도전 UI가 있습니다.
- `arena-core.js`에서 원본 시뮬레이터를 사용해 모델과 플레이어의 조작을 재생합니다.
- `paint.js`에서 지형, 착지와 추격 장면을 그립니다.
- `art/`의 푸딩 배경과 투명 젤리 스프라이트는 내장 ImageGen으로 생성하고 WebP로 인코딩했습니다.
